# KK1 Palmer Penguins Analysis

This repo contains my knowledge check 1 in the course Artificial Intelligence – Python programming.

## Subject

I analyze the Palmer Penguins dataset and investigate what morphological measurements best separate the three penguin species: Adelie, Chinstrap, and Gentoo.

## Dataset

The dataset comes from [Palmer Station LTER](https://allisonhorst.github.io/palmerpenguins/), collected by Dr. Kristen Gorman between 2007 and 2009.

Each row in the dataset represents one individual penguin. The data includes species, island, bill length, bill depth, flipper length, body mass, sex, and year.

## Question

My main question is:

**Which measurements best separate Adelie, Chinstrap, and Gentoo penguins?**
