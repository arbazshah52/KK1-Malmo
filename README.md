# KK1 – Palmer Penguins (Malmö)

First knowledge assessment: exploratory analysis of the **Palmer Penguins** dataset in a Jupyter notebook.

## Dataset

**Palmer Penguins** was collected by Dr. Kristen Gorman at Palmer Station, Antarctica (2007–2009). Each row is one measured penguin (species, island, bill/flipper/body measurements, sex, year).

- Source: [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/)
- File: `penguins.csv`

## How to run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook "KK1 Malmo.ipynb"
```

Run all cells top to bottom (`Kernel` → `Restart & Run All`). It works if there are no errors and three charts appear.
